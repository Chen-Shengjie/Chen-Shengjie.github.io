# Shengjie Chen Personal Homepage

This repository contains the source for my personal academic homepage:

https://chen-shengjie.github.io

The site is built with Jekyll using the al-folio theme.

## Local Development

```bash
docker compose up
```

The site runs locally at:

```text
http://localhost:8080
```

## Main Content

- `_pages/about.md` - homepage/about page
- `_pages/research.md` - research page
- `_pages/cv.md` - CV page
- `_bibliography/papers.bib` - publication and working-paper placeholders
- `CV.pdf` - downloadable CV
